Enable the VAAC London QVA feed

The Quantitative Volcanic Ash (QVA) feed from Met Office VAAC London became operational 27 November 2025. It is the gold-standard evidence for any ash-cloud defence — McDonagh C-12/11 pattern — and did not exist as a machine-readable feed before that date. London and Toulouse VAACs are the first two centres offering it. Free, no fee, but access is human-gated via written request.

  1. Send the subscription email to QVA@metoffice.gov.uk from harryevans15@icloud.com. Template below.
  2. Wait for VAAC London reply with API endpoint + credentials (typically 5–10 working days).
  3. Add credentials as GitHub Actions secret VAAC_QVA_KEY in the evidence-collection repository settings.
  4. Replace the stub pull() in sources/vaac_london_qva.py with the real authenticated fetch (docstring in that file has the template).
  5. Trigger a manual run from the Actions tab — the source lights up on the Evidence hub and this page starts showing live QVA advisories.
