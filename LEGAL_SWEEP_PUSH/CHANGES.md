# Legal sweep — push pack contents

Five files touched — two more than the predicted three, both found and fixed as direct consequences of the sweep itself (see report for full reasoning). All go to the repository root, overwriting existing files.

- **defendable_trees.js** — DT-05 simplified to a single concede terminal (G1 entry → G2 concede; deleted G2b/G3/G4); authority string rewritten to route external-caused events elsewhere. DT-15 downgraded from a defence-tree conclusion to an Article 4 pathway note; match regex tightened so "denied boarding" mentioned as context inside a broader delay/cancellation claim no longer hijacks the tree (confirmed via negative test). DT-01's top-level authority string: removed Moens C-159/18 (verified — that case is about runway fuel-spill closure, not ATC). DT-02's top-level authority string: upgraded Blanche v EasyJet to its full reported citation, `[2019] EWCA Civ 69` (verified as a reported Court of Appeal case, not unreported county court).
- **defendable_tree_dt01_atc.js** — its own internal `AUTHORITY` constant (separate from the wrapper string in `defendable_trees.js`, and what actually surfaces in the exit object) also cited Moens — removed there too, since fixing only the wrapper would have left the live citation unchanged.
- **defendable_type_map.js** — fixed `'political-unrest'` routing from `DT-11` to `DT-17`: DT-11's `matches()` only recognises volcanic/earthquake/flood/hurricane language and never fires on political-unrest text; DT-17 is the tree that actually has the travel-ban/airspace-closure/government-restriction gates. Also added the missing `DT-17` entry to the reverse `DT_TO_RM` map for consistency.
- **defendable_registry.js** — DT-05's conclusion-id legend: removed the now-irrelevant `DT14_HIDDEN_DEFECT_LIMB1` reference (DT-05 no longer produces that conclusion; confirmed via grep it's still validly produced by DT-14 alone, and that `defendable_confidence_manager.js`'s separate evidence-scoring table — the actual functional consumer — doesn't read from this registry file at all, so nothing broke). DT-15's conclusion question text updated to the Article 4 framing.
- **defendable_analyser_v3.html** — `LEGAL_CHAR.technical` rewritten to concede-by-default, with external-caused events and the separate hidden-defect exception (DT-14) clearly distinguished rather than blended into the same paragraph. `LEGAL_CHAR.ground-damage` rewritten from a fact-dependent third-party test to concede-by-default — it routes to DT-05 via the type map, and DT-05 no longer runs that fact-dependent inquiry, so the old text would have promised a defence the engine can no longer produce. `LEGAL_CHAR.security`'s NI, HZ v European Air Charter date corrected from 21 Jan 2026 to 4 Mar 2026 (verified — the real judgment date). New `LEGAL_CHAR.denied_boarding` entry added, matching DT-15's new Article 4 framing. Cache-bust version bumps on all five changed/loaded scripts (`defendable_trees.js`, `defendable_registry.js`, `defendable_type_map.js`, `defendable_tree_dt01_atc.js` → `?v=sessE1`).

**Not touched, by standing instruction**: `defendable_analyser.html` (v2) also loads `defendable_trees.js`/`defendable_registry.js` unversioned — it will serve the updated tree logic but its cached copy won't refresh until someone bumps its own script tags, which is out of scope here per the existing "don't touch v2" rule.
